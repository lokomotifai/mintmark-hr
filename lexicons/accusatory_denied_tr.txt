# Accusatory vocabulary this pack refuses.
#
# The criminal-record branch is this pack's sharpest edge. A reference check is a
# process: an employer requests a document and records what came back. Text that
# states a person committed an offence, was convicted, or is under investigation
# is an accusation about a person, and a synthetic person is still a person-shaped
# claim that a model can learn to produce about a real one.
#
# So the boundary is procedural: the document may say a record was requested,
# received, or is pending. It may never say what the record contains.
#
# This is the second control, not the first. The core's CRIMINAL descriptors are
# already written as document names rather than allegations. The list exists
# because review gets tired and a list does not.
#
# Matching is folded, contiguous-phrase, and word-boundary aware, the same as the
# institution denylist.
#
