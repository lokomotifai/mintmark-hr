# Pack denylist extension. One list across the pack family: the core's banks,
# every real insurer, and every real holding and industrial company a fictional
# name in any of these packs could land on. It may only grow.
#
# It is one list because the packs invent the same kinds of name. This pack
# invents employers, the banking pack invents counterparties, the insurance pack
# invents corporate insureds, and a list built for one of those cannot catch a
# collision in another. Each pack scans its own lexicons, its own templates, and
# its own minted output against this file rather than against the core's.
#
# Real Turkish financial institutions. A generated name must never collide
# with any entry here. Packs may extend this list and may never shrink it.
#
# Source: TCMB Odeme Sistemleri Katilimcilari, revision 072025.
# Retrieved: 2026-08-22. 71 participants, bank codes 0001 to 0807.
# URL: https://www.tcmb.gov.tr/wps/wcm/connect/9fa62a85-5b6d-46c5-9b01-eb461d43723d/
#
# Matching is folded, contiguous-phrase, and word-boundary aware.
#
# Two rules shape these entries, and both were learned from a miss:
#   Legal-form and category words are stripped, because every fictional bank
#   this project generates contains the word 'bank'. But a connector inside a
#   name is kept, because matching is contiguous and 'yapi kredi bankasi' never
#   appears inside 'yapi ve kredi bankasi'.
#   An entry whose distinctive part is short or is an ordinary Turkish word keeps
#   the whole name. 'is' is the brand of Turkiye Is Bankasi and also the ordinary
#   word for work; 'hayat' means life. Alone, either fires on ordinary prose.
